# Critique Report: Prefect run observability and the missing Sync API address

**Spec**: [spec.md](../spec.md) | **Plan**: [plan.md](../plan.md) | **Date**: 2026-11-05

## Executive Summary

The spec and plan restore behaviour that was approved on 2026-10-20 and that the 2026-11-05 stack test showed
missing, so the need comes from observed gaps, not from guesses. The design reuses existing seams:

- `_run_logger`'s Prefect-context flag;
- `operator_cause`'s redacted next action;
- the shared `OrchestrationSummary` model;
- `_error_fields`.

Three items must be fixed before tasks are generated:

- the order of the artifact publish relative to `secrets.clear()`;
- the log line for a failure that recorded nothing;
- the success criterion about unchanged tests, which conflicts with tightening the refused-claim test.

Verdict: ⚠️ PROCEED WITH UPDATES.
