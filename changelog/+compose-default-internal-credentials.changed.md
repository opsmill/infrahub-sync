The root `docker-compose.yml` now defaults the six credentials that only its own services use: the PostgreSQL passwords, the object store keys and the Prefect API credential. A test deployment starts with three variables set: `INFRAHUB_SYNC_ADMIN_ACCOUNT_PASSWORD`, `INFRAHUB_SYNC_ENCRYPTION_KEY` and `INFRAHUB_SYNC_WORKER_TOKEN`. Set your own values in `.env` for any deployment that holds real data.
