Plan format 4 reserves an optional `cleared_relationships` list on an update, for a later release that clears a relationship the source no longer sets. This release never writes the field. It reads it, but refuses to apply a plan whose update carries one, before any write: the engine raises `PlanFeatureNotSupportedError` and `POST /runs/{run_id}/apply` returns 409 `plan-feature-not-supported`.
