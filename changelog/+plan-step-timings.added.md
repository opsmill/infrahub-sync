The run response returns `plan_step` for each `plan` and `sync` execution: the start and the end of waiting for a worker, preparing, comparing, checking and saving the plan. `infrahub-sync runs show` prints one `plan_<part>` line per part after the read lines, with its duration, `running`, or how it stopped. Runs created before this release return `plan_step: null` and print no plan line. These timings are subject to change in a later release.
