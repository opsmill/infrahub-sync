`infrahub-sync configs validate --branch <name>` (and `?branch=<name>` on `POST /configs/{config_id}/versions/{registry_version}/validate`) checks the mapping against the destination schema of that Infrahub branch before any run: undeclared kinds and fields (`destination-schema-mismatch`), a literal `static` Dropdown value that is not one of the attribute's choices (`destination-dropdown-value-not-in-choices`), and identifiers that cannot key a create, judged by the same rule the plan applies. It also reports each credential variable the worker does not hold (`credential-not-set-in-worker`, by name, never a value), or warns with `worker-environment-unknown` when no live worker has published its variable names. To support this, each worker now writes the names of its set credential variables to the product store when it starts and on each poll.
