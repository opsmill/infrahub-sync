A stopped apply now shows how far it got: `run.failure.apply_progress` in `GET /runs/{run_id}` and the output of `apply` and `runs show` give the number of operations written out of the plan's total, and the operation that failed, with its action, kind and identity. Applying the plan of a run that already applied, or whose apply stopped, is refused with HTTP 409 and the error code `new-plan-required` (before, `run-execution-conflict`), and `infrahub-sync apply` prints "This plan was already applied or its apply stopped; create and review a new plan". Create and review a new plan with `infrahub-sync diff`: it holds only the operations that the stopped apply did not write.
