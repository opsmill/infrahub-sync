Operators can approve a reviewed plan without applying it. `infrahub-sync approve RUN_ID --expected-checksum CHECKSUM` (`POST /runs/{run_id}/approve`) records who approved which checksum and when, and writes nothing to the destination. `runs show` prints the approval, and the run resource carries it as `approval`. When the Sync API runs with `INFRAHUB_SYNC_REQUIRE_APPROVAL=true`, `apply` refuses a plan without a matching approval (`approval-required`, `approval-checksum-mismatch`), and `sync` is refused (`approval-required-for-sync`); `whoami` and `GET /me` report the setting as `approval_required`. `runs cancel` now withdraws a finished plan that was not applied, approved or not: the run moves to phase `cancelled`, and `approve` and `apply` then refuse it with `run-cancelled`.
