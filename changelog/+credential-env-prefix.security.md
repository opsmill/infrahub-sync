An `env` credential identifier in a configuration package must now start with `INFRAHUB_SYNC_CREDENTIAL_`; validation reports any other name as `malformed-credential-reference`, and the worker refuses to resolve it. Rename each identifier and the matching variable, for example `NETBOX_TOKEN` to `INFRAHUB_SYNC_CREDENTIAL_NETBOX_TOKEN`; the Compose bundle's `operator.env` now uses `INFRAHUB_SYNC_CREDENTIAL_INFRAHUB_API_TOKEN`, `INFRAHUB_SYNC_CREDENTIAL_NETBOX_TOKEN`, and `INFRAHUB_SYNC_CREDENTIAL_NAUTOBOT_TOKEN`. A version registered before this change keeps its old identifiers and its runs fail, so register a new version of each package with `configs version`.
