The adapter base class now owns the per-record load loop: each adapter lists its records and converts one record, and the base class builds and adds each record in one admission step. The NetBox, Nautobot, ACI and generic REST adapters (Peering Manager included) now list a reference to a peer that is not in the source instead of failing the load or dropping the reference. The IP Fabric adapter now reports two records with the same identity instead of keeping only the last one.
