An interrupted apply or `sync` can now continue on the same run: `verify` reports, for each operation that may have reached the destination, whether the node matches the plan, differs from it or is missing, and `runs resume RUN_ID --expected-checksum CHECKSUM` (`POST /runs/{run_id}/resume`) applies the rest of the saved plan from the last saved position. `runs show` prints how far the write got, whether the run can be resumed, and the committed, uncertain and not-reached operations of each kind.
