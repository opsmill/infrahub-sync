`infrahub-sync plan` and `infrahub-sync runs plan` print the number of left-out records, problems and kept records, the kinds whose deletes the plan does not compute, and whether Dropdown values were checked; `plan` also prints the first 20 problems. `infrahub-sync runs plan <run_id>` gains `--problems` (with `--type`), `--left-out` and `--kept`, and the Sync API gains `GET /runs/{run_id}/plan/problems`, `/plan/left-out` and `/plan/kept`, with paging and filters by problem type and kind.
