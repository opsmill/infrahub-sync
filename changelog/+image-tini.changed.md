The Sync image now starts every command through tini (`ENTRYPOINT ["/usr/bin/tini", "-g", "--"]`), as the Infrahub image does. tini passes SIGTERM to the command and to the process of each run, and removes finished orphaned processes. A `docker compose` or `docker run` command keeps tini; a Kubernetes `command:` or a `--entrypoint` override replaces it.
