A dotted schema mapping into a nested Nautobot object, such as `device_type.model`, loaded `None` and failed model validation, because Nautobot list responses return nested objects as `{id, object_type, url}` only. The Nautobot source adapter now accepts an optional `source.settings.depth` (an integer between 0 and 10) and passes it to Nautobot on every list request, so an operator can ask for the wider response those mappings need. Omit the setting and every request is unchanged.
