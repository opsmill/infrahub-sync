The web interface asks for an account name and a password, shows the signed-in account with a sign-out action, and names the account that started a run, approved a plan or registered a configuration version. It also offers a My account page to change one's password and manage one's API tokens and, for administrators, an Accounts page to create, change, disable, enable, unlock and delete accounts. For the `admin` account, whose password and API token the environment of the Sync service sets, My account only displays the tokens.
