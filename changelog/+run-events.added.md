Added `GET /events` and the `infrahub-sync events` command. They list typed events about runs and configurations, such as `infrahub_sync.run.planned` and `infrahub_sync.run.failed`, with their related account, configuration version and branch. `GET /events` filters by run, configuration, event type, related resource and time. The command filters by run, configuration and event type only, and `--follow` prints new events as they are recorded.
