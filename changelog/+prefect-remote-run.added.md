An optional Prefect integration, installed with the `prefect` extra, serves Infrahub Sync as a deployment reachable through Prefect's REST API. A remote caller selects a configured sync and an optional Infrahub branch, runs a read-only `plan`, or runs a `sync` that is refused unless `confirm_writes=true` is passed — the refusal happens before either adapter loads. The sync's own lifecycle logging is forwarded into the flow-run log, and each run returns a stable result carrying its status, per-action change counts, run id, and the runner-local artifact path. Configurations are restricted to the runner's own configured directory; credentials and endpoints stay in the runner environment and are never accepted as API parameters. Failure messages are redacted by value before they cross the remote boundary. The default self-hosted Prefect server has no authentication and is documented for localhost or another trusted environment. Saved-plan review and `apply` remain CLI workflows. The base install is unaffected and never imports Prefect.
