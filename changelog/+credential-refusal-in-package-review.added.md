When you add a configuration package in the web interface and a stored credential that it names does not exist or lacks a field, the validation finding and the refused registration now show what to do. An administrator follows a link that opens the create form or the change-value form of the "Credentials" page for that credential, then presses "Validate again". Another account is told to ask an administrator. The details page of a configuration shows the stored credential that the source and the destination name, and the "Credentials" page shows the account that created each credential and when.
