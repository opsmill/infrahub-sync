Added `infrahub_sync.testcontainers` (experimental), installed with the `testcontainers` extra on Python 3.11–3.13. Its test class `TestInfrahubSyncDocker` starts Infrahub through `infrahub-testcontainers`, then Sync from the root `docker-compose.yml`, which the package now ships. `INFRAHUB_SYNC_DOCKER_IMAGE` and `VERSION` select the Sync image, and every other variable the file reads is taken from the environment when set. A subclass adds Compose override files through the `infrahub_sync_compose_files` fixture.
