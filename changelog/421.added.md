The Sync service serves the web interface at the root of its address, on the same port as the Sync API, so an operator opens it in a browser with no other process, port or setting. A person signs in to the page with the name and the password of their account; the web interface keeps the session token for the browser tab only and sends it with every request, and "Sign out" in the page header ends the session. The image includes the built web interface and sets `INFRAHUB_SYNC_WEB_DIRECTORY` to its location; without that variable the Sync API still starts under `/api`, a browser that opens the root address receives an answer that the web interface is not included in this install, and other clients receive the JSON "not found" error.
