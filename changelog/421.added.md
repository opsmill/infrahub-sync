The Sync service serves the web interface at the root of its address, on the same port as the Sync API, so an operator opens it in a browser with no other process, port or setting. A person enters their own Sync API token in the page; the web interface keeps it for the browser tab only and sends it with every request, and "Remove token" in the status menu removes it. An operator gives each person a token through `INFRAHUB_SYNC_SERVICE_BEARER_TOKENS`. The image includes the built web interface and sets `INFRAHUB_SYNC_WEB_DIRECTORY` to its location; without that variable the Sync API still starts, and the root address answers that the web interface is not included in this install. The web interface no longer displays the actor of the token, and its development server no longer adds a token to the requests it forwards.
