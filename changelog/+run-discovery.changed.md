The CLI command that creates a plan run is now `plan`. `diff` still works as a hidden alias and prints a deprecation warning on standard error. Messages that told users to re-run `diff` now name `plan`. `GET /configs` and `GET /configs/{config_id}/versions` now return one page at a time as `{"items": [...], "next_cursor": ...}` instead of a bare array, and are paged with `limit` and `cursor`; a cursor that does not come from the previous page returns `422 invalid-cursor`. Configuration summaries add `name` and `latest_version`, and version list items omit the package content and add `registered_by`, `registration_reason`, `latest_run` (the newest run) and `latest_applied_run` (the run applied most recently, ordered by when its apply finished). `configs list` adds `--name`, `--limit` and `--all`, and `configs versions` prints each version's latest run and most recently applied run.
