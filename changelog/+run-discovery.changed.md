The CLI command that creates a plan run is now `plan`. `diff` still works as a hidden alias and prints a deprecation warning on standard error. Messages that told users to re-run `diff` now name `plan`. `GET /configs` and `GET /configs/{config_id}/versions` now return one page at a time as `{"items": [...], "next_cursor": ...}` instead of a bare array, and are paged with `limit` and `cursor`; a cursor that does not decode, or that was issued for another list or for other filters, returns `422 invalid-cursor`. Configuration summaries add `name` and `latest_version`, and version list items omit the package content and add `registered_by`, `registration_reason`, `latest_run` (the newest run) and `latest_applied_run` (the run applied most recently, ordered by when its apply finished); each run reference carries `finished_at`. In the Python client, `SyncClient.list_configs()` and `SyncClient.list_config_versions()` now return one page (`ConfigurationPage` and `ConfigurationVersionPage`, with `items` and `next_cursor`) instead of a tuple of every item, and accept `limit` and `cursor`; `list_config_versions()` items are version summaries without the package. `iter_configs()` and `iter_config_versions()` read every page. `configs list` adds `--name`, `--limit` and `--all`, and `configs versions` prints who registered each version and why, its latest run, and its most recently applied run with the time that apply finished.
