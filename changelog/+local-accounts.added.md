An administrator can now give each person a local account of the Sync API: a person signs in with `infrahub-sync login` and a password, and creates API tokens for scripts with `infrahub-sync tokens create`; an administrator manages accounts with `infrahub-sync accounts`. The deployment defines the `admin` account with `INFRAHUB_SYNC_ADMIN_ACCOUNT_PASSWORD` and the optional `INFRAHUB_SYNC_ADMIN_ACCOUNT_TOKEN`, which the Sync API applies at each start.
