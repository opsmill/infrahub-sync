Fixed schema-mapping fields declaring a falsy static value — such as `false`, `0`, `""`, `[]` or `{}` — being dropped by the NetBox and Nautobot source adapters. Any explicitly declared static value is now assigned, so a configuration that already declares one starts emitting that field to the destination, and a field that declares both `static` and `mapping` now takes the static value, as it already did for non-falsy statics.
