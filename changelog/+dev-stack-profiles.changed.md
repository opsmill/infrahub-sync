The development stack moves to `development/docker-compose.yml`. Its PostgreSQL, Silo object store and Prefect server, which runs from the development image with the UI on `127.0.0.1:4230`, always start; the Sync services start with the `sync` profile, and a local Infrahub, included from `development/docker-compose.infrahub.yml`, starts with the `infrahub` profile. The Sync-image services mount `infrahub_sync/` and `opsmill_prefect_extras/` from the checkout read-only, so a code change needs a restart and no rebuild. The image carries the label `org.opsmill.infrahub-sync.build-inputs`, which the development tasks compare with the checkout to decide whether to rebuild.
