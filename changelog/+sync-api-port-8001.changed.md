The Compose deployment's Sync API now publishes on host port 8001 by default (it was 8000), so Infrahub can keep host port 8000 on the same machine. Inside the container the Sync API still listens on port 8000. An operator who relies on host port 8000 sets `INFRAHUB_SYNC_API_PORT=8000` in `.env`, and a client that reaches the deployment sets `INFRAHUB_SYNC_API_URL=http://127.0.0.1:8001`. The development stack's Sync API moves from host port 8030 to 8001 as well, and the new `SYNC_API_PORT` variable overrides it.
