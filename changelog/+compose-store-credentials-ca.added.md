The Compose deployment can store plans and run files in an S3-compatible store the team already runs: set `INFRAHUB_SYNC_S3_ENDPOINT_URL` and `INFRAHUB_SYNC_S3_ADDRESSING_STYLE` in `.env`, and leave the bundled store out with `INFRAHUB_SYNC_BUNDLED_OBJECT_STORE=0`. `sync-bootstrap` checks for the bucket before creating it, and checks that the store refuses a second create-only write. `sync-worker` now receives the credential variables of every bundled adapter, listed by adapter on the Compose deployment page. `INFRAHUB_SYNC_CA_CERTIFICATES` names a directory of CA certificates that `sync-bootstrap`, `sync-api` and `sync-worker` trust next to the public roots. Release notes name the image by its digest, and the documented `cosign` check accepts only a signature made by the image workflow when it runs for a tag.
