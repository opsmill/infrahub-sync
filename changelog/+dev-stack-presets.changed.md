`invoke dev.start` now starts only the Sync service by default: PostgreSQL, the object store, the Prefect server, the Sync API and the worker, which syncs into an Infrahub you already run (by default `http://host.docker.internal:8000`). Choose what else starts with a preset: `--preset infrahub` (or `invoke dev.infrahub`) adds a local Infrahub, as `dev.start` did before, and `--preset preview` (or `invoke dev.preview`) also starts the local NetBox and loads the smoke dataset into Infrahub. `dev.deps` takes `--preset` too, `INFRAHUB_SYNC_DEV_PRESET` selects a preset for every task, and a task without either follows the stack's containers, which never select `preview`. `dev.seed` and `dev.smoke` need the `infrahub` or `preview` preset.
