`invoke netbox.seed --dataset demo` loads the official NetBox demo data into the local development NetBox from a SQL dump pinned to one commit and verified by SHA-256, and `invoke netbox.demo-package` writes a copy of the `from-netbox` package that points at it. `netbox.up` and `netbox.seed` used to time out after 30 minutes because the health check called `wget`, which the pinned NetBox image does not include; the check now uses `curl`, so both tasks return as soon as NetBox is ready.
