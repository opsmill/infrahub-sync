Operators can now find runs and check a token without knowing a run ID. `GET /runs` lists runs, newest first, filtered by `config_id` and `registry_version`, and each run carries its `destination_branch`. `GET /me` returns the actor a token authenticates as and its administrator flag. Each Prefect flow run that Sync submits is tagged `run:<run_id>`, `stage:<stage>` and, for a registered run, `config:<config_id>` and `config-version:<config_id>@<registry_version>`, so the stages of a run can be filtered in Prefect. The CLI adds `verify RUN_ID`, `runs list`, `runs artifacts RUN_ID`, `runs cancel RUN_ID` and `whoami`, and every command that takes a configuration accepts its name as well as its identifier.
