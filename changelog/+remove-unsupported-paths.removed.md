Removed four paths that this version does not support. Startup no longer upgrades a product database that an earlier build created: start this version on an empty database. The Sync service worker refuses a run that has no registered configuration, and it no longer reads `INFRAHUB_SYNC_CONFIG_DIRECTORY`; only the direct Prefect deployment reads that variable. The package no longer imports the Redis store of `diffsync`, and the base install no longer installs the `redis` and `tqdm` packages; a configuration with a `store` block is refused as before. The terminal progress bar is removed. `execute_run` no longer accepts `show_progress`, `verbosity`, `concurrent_load` or `allow_destination_change`, and a direct Python call to `execute_run` is not a supported use.
