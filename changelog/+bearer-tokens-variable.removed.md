The Sync API no longer reads `INFRAHUB_SYNC_SERVICE_BEARER_TOKENS`, and its tokens no longer work. Before you upgrade, set `INFRAHUB_SYNC_ADMIN_ACCOUNT_PASSWORD`, and `INFRAHUB_SYNC_ADMIN_ACCOUNT_TOKEN` if a script or the Compose `cli` service needs a token. After you upgrade, set `INFRAHUB_SYNC_API_TOKEN` of the Compose `cli` service and of each script to an API token of an account: the `admin` token at first, then a token that the account of each script creates, because the `admin` token always acts as an administrator. Create an account for each person.
