The Compose deployment now runs the Prefect server from the Sync image, so `docker compose pull` no longer pulls the `prefecthq/prefect` image. The Prefect port is no longer published on the Docker host: to open the Prefect UI, write the second Compose file `prefect-ui.yml` shown in the Compose deployment guide and name it on the command line; it publishes the port on `127.0.0.1` only. To store Sync files in your own S3-compatible store instead of the bundled MinIO, set `INFRAHUB_SYNC_S3_ENDPOINT_URL` and `INFRAHUB_SYNC_S3_ADDRESSING_STYLE` in `.env`, and set `INFRAHUB_SYNC_BUNDLED_OBJECT_STORE=0` so that Compose does not start MinIO. The 14 new `INFRAHUB_SYNC_CREDENTIAL_*` variables in `.env` now reach `sync-worker`, so every bundled adapter can read its credentials. To trust a private certificate authority, set `INFRAHUB_SYNC_CA_CERTIFICATES` to a host directory of PEM files.
