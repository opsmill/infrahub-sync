Applying a plan that leaves out records now needs the confirmation that the left-out records were reviewed: `infrahub-sync apply --confirm-left-out`, or `confirm_left_out: true` in the Sync API apply request. Without it, the apply is refused before any write with `apply refused: this plan leaves out 12 records; confirm with --confirm-left-out` (409 `left-out-confirmation-required` in the API, with the count in `left_out`). A plan that leaves out nothing applies as before, and accepts the confirmation if one is sent. The engine checks the confirmation again, so a direct Python caller of `Potenda.apply_plan` passes `confirm_left_out=True`.
