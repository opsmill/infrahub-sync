A `sync` run whose plan leaves out records now stops after the plan, before any write. The run ends with phase `planned` and outcome `left-out-review-required`, and the CLI, the last log line and the Prefect run artifact print the next step: review the plan with `infrahub-sync runs plan <run_id> --problems` and `--left-out`, then apply the run with `infrahub-sync apply <run_id> --expected-checksum <checksum> --confirm-left-out`. The stopped run can be applied once. The Prefect run artifact of a plan or `sync` stage also shows the count of records left out and the count of problems.

A plan saved in format 3, by an earlier version, can still be read and reviewed but is no longer applied: it was never checked for problems. The apply is refused with `PlanFormatApplyUnsupportedError` before any write; run `plan` again and apply the new plan.
