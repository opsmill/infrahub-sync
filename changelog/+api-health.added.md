The Sync API serves `GET /api/health`, without authentication. It checks PostgreSQL, the object store, the Prefect server and its database, and the workers of the work pool, and answers `200` when every component is up and at least `INFRAHUB_SYNC_HEALTH_MIN_WORKERS` workers (default 1) are live, and `503` otherwise. Each failed component carries one of seven error categories, such as `timeout` or `name_resolution_failed`; each check ends within `INFRAHUB_SYNC_HEALTH_CHECK_TIMEOUT` seconds (default 3). The `sync-worker` Compose service has a health check that turns the container `unhealthy` when the worker process hangs; Docker runs no health check in a paused container, which shows as paused. An outage of PostgreSQL or Prefect leaves it `healthy`.
