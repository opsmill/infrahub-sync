Prefect is now 3.8.6, the version Infrahub uses, in the `prefect` and `service` extras, and the Compose deployment's Prefect server runs `prefecthq/prefect:3.8.6-python3.13`. Prefect 3.8.6 starts a run that has no configured command through a workspace supervisor that copies code from the deployment's storage and can relaunch through `uv run`; the Sync worker instead starts every admitted run with Prefect's direct engine starter, so the child runs exactly the command the worker admitted.
