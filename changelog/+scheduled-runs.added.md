A schedule starts a sync of one configuration version at the times of a cron expression in a time zone, with no person present. An operator creates, lists, views, changes, pauses, resumes and deletes schedules with `infrahub-sync schedules` or the Sync API, and each run that a schedule starts names its schedule and its start time. A product database that an earlier build created cannot be used with this version: the Sync service refuses to start on it, because there is no in-place upgrade. Replace the product database before you upgrade.
