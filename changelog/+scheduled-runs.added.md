Add schedules: the `infrahub-sync schedules` commands and the `/schedules` routes of the Sync API create, list, show, change, pause, resume, delete and take over a schedule that starts a `sync` run of one configuration version on a cron cadence. Runs record their trigger type and schedule, and `runs list` and `events` filter on them. In this build, the Sync API refuses to create a schedule with `schedule-setting-not-available`, because neither write target of a schedule is turned on yet. A product database that an earlier build created cannot be used with this version: the Sync service refuses to start on it, because there is no in-place upgrade. Replace the product database before you upgrade.
