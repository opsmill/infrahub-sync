`uv run invoke start` now connects the local development stack's worker to the Docker network of a local Infrahub started from Infrahub's own Compose file (`infrahub_default`, or the network named by `INFRAHUB_SYNC_DEV_INFRAHUB_NETWORK`), so a package reaches Infrahub at `http://infrahub-server:8000` on every platform. `invoke netbox.demo-package --dev-stack` writes that address by default, and the NetBox demo tutorial and the development stack page use it instead of `host.docker.internal`.
