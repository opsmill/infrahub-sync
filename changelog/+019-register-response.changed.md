The responses of `POST /configs` and `POST /configs/{config_id}/versions` name the version by `config_id`, `registry_version`, `package_checksum` and `created_at`, and no longer include `declared_content`: the stored package is redacted, so it did not match the checksum shown next to it. `configs register` and `configs version` print the same fields. `GET /configs/{config_id}/versions/{registry_version}` and `configs show --version` still return the declared content. A replay of a request registered before this change returns the body stored then, which still includes `declared_content`. Upgrade the CLI together with the Sync API: an older CLI expects `declared_content` in these responses, so its `configs register` and `configs version` store the version and then fail to read the response. The registration is kept; read it with `configs show CONFIG_ID --version VERSION`.
