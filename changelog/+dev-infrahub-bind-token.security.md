`invoke dev.start`, `invoke dev.deps` and the benchmark runner now refuse to start the development stack's Infrahub when `INFRAHUB_BIND_ADDRESS` names an address other than loopback and `INFRAHUB_INITIAL_ADMIN_TOKEN` is unset, empty or the public development default. To publish Infrahub on another address, export `INFRAHUB_INITIAL_ADMIN_TOKEN` with a token of your own and use the same value as `INFRAHUB_API_TOKEN`. Infrahub applies that token only when it first initialises its database, so remove an existing stack with `invoke dev.destroy` before you start it with a new token.
