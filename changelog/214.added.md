Added an operator-owned configuration workflow to the Compose deployment. A deployment now
starts with an empty registry, no source or destination credential, and no reachable
destination: an operator registers their own configuration package afterwards through the
containerized CLI, then validates it, plans, applies against the reviewed checksum, and
reads the run and its results. The archive names the immutable image it was qualified
against and resolves it locally, so no image reference is an operator input.
