A registered run no longer reads adapter addresses, credentials, TLS verification, or Infrahub SDK credentials from the worker environment, including for an adapter declared with `settings: null`; `CISCO_APIC_VERIFY`, `IPF_URL`, `IPF_TOKEN`, `IPF_VERIFY`, `INFRAHUB_API_TOKEN`, `INFRAHUB_USERNAME`, `INFRAHUB_PASSWORD`, and `INFRAHUB_TLS_INSECURE` now apply to direct adapter use only.
