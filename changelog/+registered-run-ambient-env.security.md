A registered run no longer reads adapter addresses, credentials, TLS verification, or Infrahub SDK credentials from the worker environment, including for an adapter declared with `settings: null`; `CISCO_APIC_VERIFY`, `IPF_URL`, `IPF_TOKEN`, `IPF_VERIFY`, `IPF_SNAPSHOT`, `INFRAHUB_API_TOKEN`, `INFRAHUB_USERNAME`, `INFRAHUB_PASSWORD`, and `INFRAHUB_TLS_INSECURE` now apply to direct adapter use only. If a registered package relied on one of them, declare the setting in the package (for example `verify: false` for Cisco ACI, or `base_url` and `auth` for IP Fabric) and register a new version with `configs version`.
