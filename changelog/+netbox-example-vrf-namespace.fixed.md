The NetBox example now maps each NetBox VRF to an Infrahub IP namespace and identifies prefixes and IP addresses by that namespace, so prefixes that overlap across VRFs with distinct names no longer collapse into a single Infrahub object; VRFs sharing a name share one namespace, and objects with no VRF — along with a VRF named `default` — go to Infrahub's built-in `default` namespace. Existing imports keep their old prefixes and addresses in the `default` namespace: adopting the updated example does not move or clean up those old objects. Records that still resolve to `default` match their existing objects there; only records that now resolve to a VRF-named namespace get new objects alongside the old ones.
