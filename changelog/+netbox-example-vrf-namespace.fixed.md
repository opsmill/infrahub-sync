The NetBox example now maps each NetBox VRF to an Infrahub IP namespace and identifies prefixes and IP addresses by that namespace, so prefixes that overlap across VRFs with distinct names no longer collapse into a single Infrahub object; VRFs sharing a name share one namespace, and objects with no VRF — along with a VRF named `default` — go to Infrahub's built-in `default` namespace. Existing imports keep their old prefixes and addresses in the `default` namespace: adopting the updated example creates namespaced replacements alongside them and does not move or clean up the old objects.
