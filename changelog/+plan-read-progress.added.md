While a Plan or a `sync` runs, `infrahub-sync runs show` prints a `source_read` and a `destination_read` line with the read state of each side: waiting, reading, succeeded with the read mode and the node count of each kind, or failed with the class name of the error. When the stage ends before a side's read ends, that side shows `not_started` or `interrupted`. The Sync API returns the same state in `reads` on each orchestration entry of a run, and the run log holds one line for each side when its read ends.
