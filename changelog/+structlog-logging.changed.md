Every `infrahub_sync` module now logs through `structlog`, and one shared configuration delivers each event through standard `logging`. The modules that already used `structlog` (health, liveness, schedules, automatic resume, the web interface, and the Webex adapter) used to print their lines to standard output with a timestamp, without the configured log level and without any `logging` handler. Their lines now follow the level and the handlers of the `infrahub_sync` logger, with each key-value pair in the message as `key=value`. A line logged inside a flow run appears in the Prefect run log with collected secrets redacted. In the Sync API process, the lines are written to standard error as `LEVEL | infrahub-sync | message`. Each service process now reports every `infrahub_sync` module at INFO, not only the bootstrap job and the CA bundle report. DiffSync events also follow the level of the `diffsync` logger and its handlers.
