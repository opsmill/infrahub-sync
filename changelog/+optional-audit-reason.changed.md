`--reason` is now optional for `configs register`, `configs version`, `diff`, `sync`, and `apply`. The Sync API accepts run, verify, apply, cancel, and configuration requests without a reason, and still refuses an empty one. When a request has no reason, the audit history records it without one. On startup, the product database changes its `reason` columns in `mutation_receipts` and `audit_events` to allow no value, on SQLite and PostgreSQL. The documentation shows the CLI as `infrahub-sync <command>`, and mentions the Compose `cli` service as an alternative.
