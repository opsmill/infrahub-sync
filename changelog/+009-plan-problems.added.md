One plan now lists every problem in the source data, of eight named types. The plan leaves out each record with a problem and each record that depends on one through a required relationship, keeps a record that refers to a left-out record only through an optional relationship without that relationship, and saves the list in plan format 4. Two or more Infrahub objects of one kind with the same configured identity are the problem `destination_identity_ambiguous`, which names the kind, the identity and the Infrahub IDs of the objects; the plan leaves out the source record with that identity and plans no create, update or delete for that identity, where before it kept the last object it read. `infrahub-sync runs problems`, `runs left-out` and `runs kept` list the entries, and the Sync API returns them from `GET /runs/{run_id}/plan/problems`, `/plan/left-out` and `/plan/kept`. Plans saved by earlier releases must be planned again before apply.
