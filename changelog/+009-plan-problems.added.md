One plan now lists every problem in the source data, of seven named types. The plan leaves out each record with a problem and each record that depends on one through a required relationship, keeps a record that refers to a left-out record only through an optional relationship without that relationship, and saves the list in plan format 4. `infrahub-sync runs problems`, `runs left-out` and `runs kept` list the entries, and the Sync API returns them from `GET /runs/{run_id}/plan/problems`, `/plan/left-out` and `/plan/kept`.
