## Use this adapter

In a [configuration package](../configuration-package.mdx), name `genericrestapi` as the source and set its `url` to the Device42 API. Then register the package, create and review a plan, and apply the plan, as described in [Run a sync](../running-a-sync.mdx).

## Overview

[Device42](https://www.device42.com/) is a commercial IT infrastructure and asset management platform. It discovers and inventories physical and virtual infrastructure — servers, network devices, applications, services — and tracks the dependencies between them.

## Sync directions supported

- Device42 → Infrahub

:::info

There is no dedicated Device42 adapter. Device42 is read through the
[Generic REST API adapter](./genericrestapi.mdx), which supports only **one-way synchronization**
from Device42 to Infrahub. Writing data back into Device42 is not supported.

:::

## Configuration

The repository contains a mapping example: [`examples/device42_to_infrahub/config.yml`](https://github.com/opsmill/infrahub-sync/blob/feature/v3-develop/examples/device42_to_infrahub/config.yml). It is a `config.yml` file, not a package, and registration refuses it as it is. To use it, convert it as described in [Convert a config.yml file](../configuration-package.mdx#convert-a-configyml-file).

The package declares the Device42 connection in `source.settings`. Credentials are `$credential` references:

```yaml
format_version: 1
configuration:
  name: from-device42
  source:
    name: genericrestapi
    settings:
      url: "https://device42.example.com"
      api_endpoint: "/api/1.0"
      auth_method: "basic"
      username:
        $credential: device42-username
      password:
        $credential: device42-password
      response_key_pattern: "objects"
  destination:
    name: infrahub
    settings:
      url: "https://infrahub.example.com"
      token:
        $credential: infrahub-token
credentials:
  device42-username:
    provider: env
    identifier: DEVICE42_USERNAME
  device42-password:
    provider: env
    identifier: DEVICE42_PASSWORD
  infrahub-token:
    provider: env
    identifier: INFRAHUB_API_TOKEN
```

See the [Generic REST API adapter](./genericrestapi.mdx) page for the full settings reference and for how the adapter reads each response.
