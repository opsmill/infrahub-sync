## V3 route

Prepare a [configuration package](../configuration-package.mdx) and register it. Then create and review a plan before applying the reviewed plan or running a confirmed sync; [Run a sync](../running-a-sync.mdx) has the canonical procedure.

## Overview

[Device42](https://www.device42.com/) is a commercial IT infrastructure and asset management platform. It discovers and inventories physical and virtual infrastructure — servers, network devices, applications, services — and tracks the dependencies between them.

## Sync directions supported

- Device42 → Infrahub

:::info

There is no dedicated Device42 adapter. Device42 is read through the
[Generic REST API adapter](./genericrestapi.mdx), which supports only **one-way synchronization**
from Device42 to Infrahub. Writing data back into Device42 is not supported.

:::

## Configuration

<ReferenceLink title="Example mapping" url="https://github.com/opsmill/infrahub-sync/tree/main/examples/device42_to_infrahub" openInNewTab />

<Tabs>
  <TabItem value="Source example" default>

  ```yaml
  ---
  name: from-device42
  source:
    name: genericrestapi
    settings:
      url: "https://<DEVICE42-ENDPOINT>"
      auth_method: "basic"
      username: "<USERNAME>"
      password: "<PASSWORD>"
      api_endpoint: "/api/1.0"
      response_key_pattern: "objects"

  destination:
    name: infrahub
    settings:
      url: "http://localhost:8000"
  ```

  </TabItem>
</Tabs>
