## Use this adapter

In a [configuration package](../configuration-package.mdx), name `genericrestapi` as the source and set its `url` to the PeeringDB API. Then register the package, create and review a plan, and apply the plan, as described in [Run a sync](../running-a-sync.mdx).

## Overview

[PeeringDB](https://www.peeringdb.com/) is a free, public, user-maintained database of network peering information. It catalogs autonomous systems, internet exchanges, points of presence, and facilities — the data networks use to find and arrange interconnection with one another.

There is no dedicated PeeringDB adapter. PeeringDB is read through the
[Generic REST API adapter](./genericrestapi.mdx), pointed at the PeeringDB API.

## Sync directions supported

- PeeringDB → Infrahub

:::info

PeeringDB is read through the Generic REST API adapter, which supports only **one-way synchronization** from PeeringDB to Infrahub. PeeringDB is a community-maintained reference database; writing data back into it is not supported.

:::

## Configuration

The repository contains a mapping example: [`examples/peeringdb_to_infrahub/config.yml`](https://github.com/opsmill/infrahub-sync/blob/feature/v3-develop/examples/peeringdb_to_infrahub/config.yml). It is a `config.yml` file, not a package, and registration refuses it as it is. To use it, convert it as described in [Convert a config.yml file](../configuration-package.mdx#convert-a-configyml-file).

The package declares the PeeringDB connection in `source.settings`. Credentials are `$credential` references:

```yaml
format_version: 1
configuration:
  name: from-peeringdb
  source:
    name: genericrestapi
    settings:
      url: "https://www.peeringdb.com"
      api_endpoint: "api"
      auth_method: "api-key" # Or "none" for PeeringDB's public, rate-limited access
      token:
        $credential: peeringdb-api-key
      response_key_pattern: "data" # PeeringDB wraps lists under "data"
  destination:
    name: infrahub
    settings:
      url: "https://infrahub.example.com"
      token:
        $credential: infrahub-token
credentials:
  peeringdb-api-key:
    provider: env
    identifier: PEERINGDB_API_KEY
  infrahub-token:
    provider: env
    identifier: INFRAHUB_API_TOKEN
```

See the [Generic REST API adapter](./genericrestapi.mdx) page for the full settings reference and for how the adapter reads each response.
