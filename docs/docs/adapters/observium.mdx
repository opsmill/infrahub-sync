## Use this adapter

In a [configuration package](../configuration-package.mdx), name `genericrestapi` as the source and set its `url` to the Observium API. Then register the package, create and review a plan, and apply the plan, as described in [Run a sync](../running-a-sync.mdx).

<!-- vale off -->
## What is Observium?

<!-- vale on -->
Observium is a network monitoring platform that delivers auto-discovery, detailed performance metrics, and rich visualizations to help you effectively manage and optimize your network infrastructure.

## Sync directions supported

- Observium → Infrahub

:::info

There is no dedicated Observium adapter. Observium is read through the
[Generic REST API adapter](./genericrestapi.mdx), which supports only **one-way synchronization**
from Observium to Infrahub. Writing data back into Observium is not supported.

:::

## Configuration

The repository contains a mapping example: [`examples/observium_to_infrahub/config.yml`](https://github.com/opsmill/infrahub-sync/blob/feature/v3-develop/examples/observium_to_infrahub/config.yml). It is a `config.yml` file, not a package, and registration refuses it as it is. To use it, convert it as described in [Convert a config.yml file](../configuration-package.mdx#convert-a-configyml-file).

The package declares the Observium connection in `source.settings`. Credentials are `$credential` references:

```yaml
format_version: 1
configuration:
  name: from-observium
  source:
    name: genericrestapi
    settings:
      url: "https://observium.example.com"
      api_endpoint: "api/v0"
      auth_method: "basic"
      username:
        $credential: observium-username
      password:
        $credential: observium-password
  destination:
    name: infrahub
    settings:
      url: "https://infrahub.example.com"
      token:
        $credential: infrahub-token
credentials:
  observium-username:
    provider: env
    identifier: OBSERVIUM_USERNAME
  observium-password:
    provider: env
    identifier: OBSERVIUM_PASSWORD
  infrahub-token:
    provider: env
    identifier: INFRAHUB_API_TOKEN
```

See the [Generic REST API adapter](./genericrestapi.mdx) page for the full settings reference and for how the adapter reads each response.
