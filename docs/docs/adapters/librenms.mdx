## Use this adapter

In a [configuration package](../configuration-package.mdx), name `genericrestapi` as the source and set its `url` to the LibreNMS API. Then register the package, create and review a plan, and apply the plan, as described in [Run a sync](../running-a-sync.mdx).

<!-- vale off -->
## What is LibreNMS?
<!-- vale on -->

LibreNMS is an open-source network monitoring system that automatically discovers, monitors, and alerts on your network devices using pre-configured setups, providing comprehensive insights for proactive network management.

## Sync directions supported

- LibreNMS → Infrahub

:::info

There is no dedicated LibreNMS adapter. LibreNMS is read through the
[Generic REST API adapter](./genericrestapi.mdx), which supports only **one-way synchronization**
from LibreNMS to Infrahub. Writing data back into LibreNMS is not supported.

:::

## Configuration

The repository contains a mapping example: [`examples/librenms_to_infrahub/config.yml`](https://github.com/opsmill/infrahub-sync/blob/feature/v3-develop/examples/librenms_to_infrahub/config.yml). It is a `config.yml` file, not a package, and registration refuses it as it is. To use it, convert it as described in [Convert a config.yml file](../configuration-package.mdx#convert-a-configyml-file).

The package declares the LibreNMS connection in `source.settings`. Credentials are `$credential` references:

```yaml
format_version: 1
configuration:
  name: from-librenms
  source:
    name: genericrestapi
    settings:
      url: "https://librenms.example.com"
      api_endpoint: "api/v0"
      auth_method: "x-auth-token"
      token:
        $credential: librenms-token
  destination:
    name: infrahub
    settings:
      url: "https://infrahub.example.com"
      token:
        $credential: infrahub-token
credentials:
  librenms-token:
    provider: env
    identifier: INFRAHUB_SYNC_CREDENTIAL_LIBRENMS_TOKEN
  infrahub-token:
    provider: env
    identifier: INFRAHUB_SYNC_CREDENTIAL_INFRAHUB_API_TOKEN
```

See the [Generic REST API adapter](./genericrestapi.mdx) page for the full settings reference and for how the adapter reads each response.
